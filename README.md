# Apartment Bill Payment System
سیستم مدیریت قبض آپارتمان

## Technologies
- PHP
- JavaScript
- MySQL
- Bootstrap

## Installation
1. Install XAMPP
2. Put project in htdocs folder
3. Import paybills.sql in phpMyAdmin
4. Configure DB.php with your database info

## Default Login
- Username: admin

## Features
- Separate login for manager and residents
- Bill management system
- Full admin panel
